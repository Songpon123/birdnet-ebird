# BirdNET → eBird clipper (macOS / Windows)

โปรแกรมบน Mac (และรุ่น Windows ที่สร้างจากโฟลเดอร์นี้) สำหรับไฟล์เสียงภาคสนามยาว ๆ: ให้ BirdNET หาเสียงนก ตัดเป็นคลิปพร้อมอัปโหลด
eBird / Macaulay Library แล้วให้คนฟังตรวจทีละคลิปก่อนคัดลอกคลิปที่ยืนยันแล้วไปโฟลเดอร์ `Ready/`
ทุกผลจาก AI เป็น "ตัวเลือกให้ตรวจ" ไม่ใช่การยืนยันชนิด

> ฉบับย่อสำหรับเริ่มใช้ (ไทย/อังกฤษ) อยู่ที่ `อ่านก่อนใช้.txt`
>
> เดินอัดต่อเนื่องด้วย Zoom H4essential, ใช้ MARK ย้อนหาเสียง และเตรียมใช้ XY คู่กับ NTG5:

## 1. ภาพรวม

```
ไฟล์เสียงยาว (WAV/MP3/FLAC/M4A/OGG/AIFF)
  │  อ่านวันเวลา/พิกัด: metadata ในไฟล์ → ชื่อไฟล์ → เวลาไฟล์ของเครื่องอัด → กรอกเอง
  ▼
BirdNET 3.0 preview (หรือรุ่นย่อ 3.0-pruned) ฟังทีละ 3 วินาที เลื่อนทีละ 1.5 วินาที
  │  ตัวกรองพื้นที่/ฤดู (พิกัด + สัปดาห์)      ตัดชนิดที่ไม่ควรมีที่นั่นช่วงนั้น
  │  ตัวกรองถิ่นอาศัย (ถ้าติ๊ก)                 นกน้ำในจุดที่ไม่มีน้ำต้องคะแนนสูง
  │  Second look (3.0)                         เสียงที่เกือบเจอ ฟังซ้ำแบบวางหน้าต่างตรงเสียง
  ▼
รวมเสียงของชนิดเดียวกันที่ห่างกัน ≤ 5 วิ เป็น 1 occurrence → ตัดคลิปจากไฟล์ต้นฉบับ
  │  เผื่อหน้า/หลัง 3 วิ, คง sample rate/bit depth/stereo ตามที่อัด, normalize peak −3 dBFS
  ▼
<โฟลเดอร์ผลลัพธ์>/<วันที่อัด>/<เวลาเริ่มอัด>/<ชนิด>/*.wav + spectrogram .png + summary.xlsx
  │
  ▼
แท็บ Review clips: ฟัง, ดู spectrogram (แบบ Macaulay ทีละ 6 วิ), เทียบเสียงอ้างอิง, Second opinion, เช็ก eBird
  │  Approve (ให้คะแนนคุณภาพ 1–5 ด้วยคน) / Reject / Not sure / Keep pending
  ▼
<วันที่อัด>/Ready/<checklist>/<ชนิด>/…_R<คะแนน>.wav   → อัปโหลด eBird / Macaulay Library (คลิปที่มีชนิดอื่นติดมาขึ้นต้นด้วย with-<ชนิด>__)
```

ไฟล์ต้นฉบับไม่ถูกแก้ไข ผลทุกอย่างอยู่ในโฟลเดอร์ผลลัพธ์ (ค่าเริ่มต้น `~/BirdNET_eBird`; เสียงที่อยู่ใน `<YYYYMMDD>/Sounds` เก็บผลที่ `Sounds/Done` ของวันนั้น)

## 3. เปิดโปรแกรม และส่งให้เพื่อน

### เปิดโปรแกรม
- **ดับเบิลคลิก `BirdNET eBird.app` บน Desktop** — เป็นตัวเปิดที่ชี้ไปยังโฟลเดอร์
  `Projects/Sound Recording/Programs/BirdNET-eBird-mac` (อย่าย้ายโฟลเดอร์นี้) log ของตัวเปิดอยู่ที่
  `~/Library/Logs/BirdNET-eBird.log`
- หรือดับเบิลคลิก **`BirdNET-eBird.command`** ในโฟลเดอร์โปรแกรม (ใช้ได้กับทุกตำแหน่งที่วางโฟลเดอร์)

### ส่งให้เพื่อน
1. **ใช้สคริปต์สร้าง zip** (แนะนำ) — ได้ `BirdNET-eBird-mac-share.zip` บน Desktop
   พร้อมโมเดล BirdNET 3.0 แต่**ไม่มี API key ของคุณ** (`data/settings.json`), cache, backup, tests:
   ```bash
   "/Users/<you>/Desktop/Projects/Sound Recording/Programs/BirdNET-eBird-mac/tools/make_share_zip.sh"
   ```
2. ถ้าคัดลอกเอง: ส่งทั้งโฟลเดอร์โปรแกรม แต่**ห้ามใส่ `data/settings.json`** (มี API key) และไม่ต้องใส่
   `data/cache/`, `_backup-before-upgrade/` (1.9 GB), `tests/`, `accuracy_cases/`,
   `__pycache__` — อย่าส่ง `BirdNET eBird.app` บน Desktop อย่างเดียว เพราะเป็นแค่ทางลัดไปยังโฟลเดอร์ในเครื่องคุณ
3. ครั้งแรกบนเครื่องเพื่อน macOS จะกันไว้ (โปรแกรมไม่ได้ลงชื่อกับ Apple):
   ดับเบิลคลิก `BirdNET-eBird.command` → ขึ้นว่าเปิดไม่ได้ → **System Settings › Privacy & Security
   › Open Anyway** (Sequoia เลิกให้คลิกขวา › Open แล้ว) ครั้งต่อไปดับเบิลคลิกได้เลย
   ตัว `.command` จะปลดการกักกัน (quarantine) ไฟล์ที่เหลือให้เอง
   หรือใช้ Terminal: `xattr -dr com.apple.quarantine /path/to/BirdNET-eBird-mac`
4. มีโมเดลใน `data/birdnet/` แล้ว เพื่อนวิเคราะห์ได้โดยไม่ต้องต่อเน็ต; xeno-canto / eBird ต้องใช้
   API key ของตัวเอง (ใส่ในแท็บ Settings)

### รุ่น Windows (ส่งให้เพื่อนที่ใช้ Windows 10/11 64-bit)
สร้างบน Mac เครื่องนี้ ได้ `BirdNET-eBird-win.zip` บน Desktop (~700 MB, มีโมเดล, ไม่มี API key):
```bash
"/Users/<you>/Desktop/Projects/Sound Recording/Programs/BirdNET-eBird-mac/tools/build_windows.sh"
```
- ใช้โค้ด `app/` และโมเดล `data/birdnet/` ชุดเดียวกับรุ่น Mac แก้โค้ดแล้วสร้างใหม่ได้ทันที
- ใส่ Python 3.12.13 ของ Windows (python-build-standalone), แพ็กเกจรุ่นเดียวกับ Mac
  (`tools/windows/requirements-windows.txt`) และ FFmpeg 9.0 LGPL ของ BtbN (มี ffplay ไว้เล่นเสียง)
  ไฟล์ที่ดาวน์โหลดตรวจ SHA-256 ทุกครั้ง เก็บไว้ใน `build/windows-cache/`
- ใส่ VC++ runtime ของ Microsoft ข้าง `python.exe` เพื่อนจึงไม่ต้องติดตั้ง VC++ Redistributable และทุกครั้งที่สร้าง
  `tools/windows/check_dlls.py` ตรวจว่าทุก .dll/.pyd หา DLL ที่ต้องใช้เจอ (กัน "DLL load failed" บนเครื่องเพื่อน)
- ฝั่งเพื่อน: คลิกขวา zip › Properties › Unblock → แตกไว้ที่สั้น ๆ เช่น `C:\BirdNET-eBird-win` →
  ดับเบิลคลิก `Create desktop shortcut.bat` ครั้งเดียว (หรือ `BirdNET eBird.bat`) ขั้นตอนเต็มอยู่ใน
  `README-Windows.txt` ในไฟล์ zip
- ต่างจาก Mac: เล่นเสียงด้วย ffplay, ปุ่ม Stop ส่งคำสั่งหยุดทาง stdin (Windows ไม่มี SIGTERM จริง),
  log อยู่ที่ `data\logs\BirdNET-eBird.log`, ถ้าโฟลเดอร์เขียนไม่ได้ข้อมูลไปอยู่ `%LOCALAPPDATA%\BirdNET-eBird`

## 4. ใช้งานแบบเร็ว

1. กด **Choose audio file** หรือ **Choose audio folder** (แถบบนสุด)
2. หน้าต่าง **Recording details** แสดงวันเวลา/พิกัดที่อ่านได้ กรอกเฉพาะที่ขาด
   (วันที่พิมพ์ `20261006`, เวลา `0929`, พิกัด `30.5928,114.3055` หรือวางลิงก์ Google Maps)
   ติ๊ก **Site habitat** ถ้าต้องการ (เช่น Forest หรือ Forest + Marsh) แล้วกด **Start analysis**
3. รอจนแถบล่างขึ้น Done — แอปเปิดแท็บ **Review clips** ให้เอง
4. เลือกคลิป → ฟัง (คลิกภาพตรงไหนก็เล่นจากตรงนั้น หรือ ▶ Play) → ดู spectrogram (**Listen tools…** = ภาพใหญ่),
   Second opinion, บรรทัด eBird
   → แก้ชื่อชนิดถ้าผิด → ให้ **Audio quality 1–5** → **✓ Approve → Ready** หรือ **Reject**
5. อัปโหลดไฟล์ใน `Ready/` ขึ้น eBird / Macaulay Library

เปิดโปรแกรมครั้งหน้า แท็บ Review clips จะกลับมาที่ผลชุดล่าสุดเอง ไม่ต้องวิเคราะห์ใหม่

## 5. หน้าจอแต่ละส่วน

### แถบด้านบน
| ปุ่ม | ทำอะไร |
|---|---|
| Choose audio file / Choose audio folder | เลือกไฟล์หรือทั้งโฟลเดอร์ (รวมโฟลเดอร์ย่อย เช่น `Raw/261030_062349/` ของ Zoom; ข้ามผลวิเคราะห์และไฟล์ซ่อน) แล้วเปิดหน้าต่าง Recording details |
| ▶ Analyze | กดได้ตลอด ยังไม่ได้เลือกเสียง = เปิดหน้าเลือกโฟลเดอร์ที่ `Sounds/Raw` ของวันใน Output, เลือกแล้ว = วิเคราะห์ไฟล์/โฟลเดอร์นั้นอีกครั้ง (ใช้ค่าปัจจุบันในแท็บ Settings) |
| Open output folder | เปิดโฟลเดอร์ผลลัพธ์ใน Finder |

ใต้ปุ่มแสดงไฟล์ที่เลือก, ข้อมูลที่ตรวจเจอ และโมเดลที่ใช้

### หน้าต่าง Recording details (ขึ้นทุกครั้งก่อนวิเคราะห์)
- แสดงวันเวลาพร้อมที่มา (embedded metadata / filename / file times …) และพิกัด
- ขอเฉพาะค่าที่ขาด: วันที่ (`YYYYMMDD`), พิกัด, เวลาเริ่ม (`HHMM`) ถ้าไฟล์มีแต่วันที่
- โฟลเดอร์หลายไฟล์: ค่าที่กรอกใช้เติมเฉพาะไฟล์ที่ขาด ไฟล์ที่มี metadata ใช้ของตัวเอง
- **Site habitat**: Forest, Field / farmland, Marsh / lake, River / stream, Sea / coast
  เลือกได้หลายอย่าง ไม่ติ๊ก = ไม่ตรวจถิ่นอาศัย (ดู [6.4](#64-ตัวกรองถิ่นอาศัย-avonet))

### แท็บ Settings
แบ่งเป็นหมวด Field logs, Recording, BirdNET, Clips และ API keys — เลือกไฟล์และเริ่มวิเคราะห์จากปุ่มแถบบน
ช่อง Date, Start time และ Coordinates กรอกเฉพาะเมื่อต้องการแทนค่าในไฟล์และ Field log: กรอกแล้วกด **Analyze** แอปใช้ค่านี้กับทุกไฟล์ (เลือกไฟล์ใหม่แล้วช่องจะว่าง)

| ตั้งค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| Output folder | `~/BirdNET_eBird` | ที่เก็บผล — เลือกเสียงใน `<YYYYMMDD>/Sounds` แล้ว Output เปลี่ยนเป็น `Sounds/Done` ของวันนั้นให้เอง (เลือกที่อื่นทับได้หลังเลือกเสียง) |
| Coordinates or Google Maps link | – | พิกัดจุดบันทึก |
| Date if no metadata / Start time | – | ใช้เมื่อไฟล์ไม่มีข้อมูล |
| Place | – | ชื่อสถานที่ เก็บใน summary |
| min_conf | 0.5 | คะแนน BirdNET ขั้นต่ำ (2.4 ทาง command line: 0.25) |
| BirdNET model | 3.0-preview | หรือ **3.0-pruned** = รุ่นย่อ เพื่อเปรียบเทียบ (ผลแยกโฟลเดอร์ `_v3pruned`) — ข้อ 6.2 |
| Site habitat | ไม่ติ๊ก | เหมือนในหน้าต่าง Recording details |
| occurrence gap (s) | 5.0 | เสียงห่างกันไม่เกินนี้ = occurrence เดียวกัน |
| lead / tail (s) | 3.0 / 3.0 | เผื่อก่อนเสียงแรก/หลังเสียงสุดท้าย |
| normalize dBFS | −3.0 | ระดับ peak ของคลิป |
| analysis overlap (s) | 1.5 | หน้าต่าง 3 วิ เลื่อนทีละ (3 − overlap) วิ |
| also keep out-of-area ≥ | ปิด (0.7) | เก็บชนิดนอกพื้นที่/ฤดูที่คะแนนถึงเกณฑ์ ไว้ตรวจนกหลงถิ่น |
| to mono | ปิด | stereo → mono (ปิด = คลิปเป็น stereo ตามที่อัด ตามคู่มือ Macaulay) |
| mel-spectrogram | เปิด | สร้างภาพ .png ต่อคลิป (มีกรอบ) |
| alt species | เปิด | บันทึกชนิดอื่นที่ BirdNET เจอช่วงเดียวกัน |
| cut unknown | ปิด | ตัดเสียงที่คะแนนต่ำกว่า min_conf ไปโฟลเดอร์ `_Unknown/` |
| force redo | ปิด | วิเคราะห์ใหม่แม้เคยทำแล้ว และ**ล้างผลตรวจกลับเป็น Pending** |
| use file time | ปิด | บังคับใช้เวลาไฟล์ (ไม่ตรวจความสอดคล้อง) |
| Keep first-to-last call continuous | ปิด | ต่อเสียงของชนิดเดียวกันเป็นช่วงยาวช่วงเดียว (ใช้เมื่อมั่นใจว่าเป็นตัวเดียวกัน) |
| Second look at near misses (3.0) | เปิด | เสียงที่คะแนน 0.2 ถึง min_conf ให้ BirdNET ฟังซ้ำแบบวางหน้าต่างตรงเสียง ถึง min_conf = ตัดเป็นคลิป (ข้อ 6.3b) |
| xeno-canto API key / eBird API key | – | key ของคุณเอง ใช้กับตัวช่วยตรวจ (ข้อ 7) |

### แท็บ Merge clips
รวมหลายคลิปของ **นกตัวเดียวกัน** (ตามแนวทาง eBird) เป็นไฟล์เดียว: ตัดเงียบหัวท้าย คั่นด้วยเงียบ 1 วิ
normalize −3 dBFS — Add…, เรียงด้วย Up/Down, กด Merge

### แถบสถานะงาน (ล่างสุด เห็นตลอด)
- **Show details / Hide details**: ช่อง log ของงาน (ลากเส้นแบ่งปรับขนาดได้)
- แถบความคืบหน้า + สถานะ เช่น `Analyzing REC-002.WAV (file 1/2) · 05:12 · 2 queued`
- **■ Stop**: หยุดงานที่รันอยู่ ไฟล์ที่เสร็จแล้วยังอยู่ รันซ้ำจะทำต่อจากที่เหลือ
- **Jobs…**: งานที่รันอยู่ + คิว; ระหว่างงานรัน เลือกไฟล์ใหม่ได้เลย งานจะต่อคิวแล้วเริ่มเอง
  เอางานออกจากคิว / Stop all ได้ในหน้าต่างนี้
- ปิดโปรแกรมระหว่างวิเคราะห์ได้ (ถามยืนยันก่อน) — หยุดอย่างปลอดภัยเหมือนกด Stop
- **Shut down when done**: ติ๊กแล้ว เมื่องานทั้งหมดเสร็จ (รวมงานเบื้องหลังเช่น Auto-checks และไม่มีงานใหม่ 15 วิ) จะขึ้น
  หน้าต่างนับถอยหลัง 60 วิ (Cancel / Shut down now) แล้วปิดเครื่อง — ใช้ครั้งเดียว ไม่จำไว้; mac ครั้งแรก macOS ถามสิทธิ์ให้
  BirdNET eBird สั่ง System Events (ถ้าไม่ได้: System Settings → Privacy & Security → Automation); Windows ใช้ `shutdown /s`
- งานที่คุณสั่ง (วิเคราะห์/รวมคลิป) มาก่อนงานเบื้องหลังเสมอ: งานเบื้องหลังที่รันอยู่จะหยุดอย่างปลอดภัยแล้วทำต่อทีหลัง
- Cmd+Q (และการที่ระบบสั่งปิดเครื่อง) ผ่านขั้นตอนปิดโปรแกรมปกติ: งานที่รันอยู่หยุดอย่างปลอดภัย

## 6. การวิเคราะห์ทำงานอย่างไร

### 6.1 วันเวลาและพิกัด
ลำดับที่ใช้ (ค่าที่กรอกเองมาก่อนเสมอ):
1. **Metadata ในไฟล์**: QuickTime creation date (มี timezone), BWF bext (เวลาเครื่องอัด),
   `creation_time` (UTC), INFO/ICRD, XMP — พิกัดจาก ISO 6709 / XMP GPS
2. **ชื่อไฟล์**: เช่น `2026-10-01 12_22.wav`, `20260608`, `YYYYMMDDHHMMSS` (ปี พ.ศ. ≥ 2400 แปลงเป็น ค.ศ.)
3. **เวลาไฟล์ของเครื่องอัด** — ใช้เฉพาะเมื่อ *เวลาสร้าง + ความยาวเสียง ≈ เวลาแก้ไข*
   (คลาดได้ 2% ของความยาว, อย่างน้อย 5 วิ ไม่เกิน 2 นาที; ไฟล์ยาว ≥ 30 วิ)
   ไฟล์ที่ถูกคัดลอกจนเวลาเปลี่ยน/ถูกแก้ไขทีหลังจะไม่ผ่าน แล้วแอปจะถาม
4. **กรอกเอง** (Recording details / Settings / CLI)

เวลาที่มี timezone (เช่น UTC จากไฟล์ m4a ของมือถือ) แปลงเป็น **time zone ของเครื่อง Mac**
ให้ตั้ง time zone ของเครื่องตรงกับจุดที่บันทึก (System Settings › General › Date & Time)

พิกัดไม่ถูกเดาเอง: ไม่มีใน metadata = ต้องกรอก ลิงก์ Google Maps ใช้ตำแหน่งหมุด (`!3d…!4d…`)
ก่อนจุดกลางแผนที่ (`@lat,lon`)

### 6.2 BirdNET
- **ชื่อชนิดตาม eBird** (eBird/Clements 2025 — ชื่อที่ต้องใช้ตอนอัปโหลด): ป้ายชื่อของ BirdNET ใช้รายชื่อชุดเก่า
  1,564 จาก 9,834 ชนิดนกชื่ออังกฤษต่างจาก eBird (Black-throated Bushtit = Black-throated Tit, Grey Heron = Gray Heron,
  Common Moorhen = Eurasian Moorhen) และ 58 ชนิดชื่อวิทยาศาสตร์ต่าง (*Charadrius dubius* = *Thinornis dubius*)
  แอปแปลงเป็นชื่อ eBird ทันทีหลัง BirdNET ฟัง (ไม่ต้องต่อเน็ต — `app/species_names.py` ใช้ข้อมูลใน
  `assets/country_checklists.csv`) ชื่อเดิมเก็บในคอลัมน์ *BirdNET name*; ~166 ชนิดที่ eBird แยก/รวมต่างออกไป
  จับคู่ไม่ได้ จะคงชื่อของ BirdNET ไว้ (ตรวจชื่อก่อน Approve)
- ผลที่วิเคราะห์ไว้ก่อนหน้า: ชื่อโฟลเดอร์/ไฟล์ยังเป็นชื่อของ BirdNET แต่ตารางในแท็บ Review และช่อง Reviewed name
  แสดงชื่อ eBird ให้ (Approve แล้วสำเนาใน Ready/ ใช้ชื่อ eBird) ถ้าวิเคราะห์ไฟล์เดิมใหม่ คลิปที่เสียงเหมือนเดิม
  ทุกไบต์ที่ตำแหน่งเดิมจะได้ผลตรวจเดิมกลับมา แม้ชื่อไฟล์เปลี่ยนตามชื่อชนิด
- **3.0 preview (ค่าเริ่มต้น)**: แพ็กเกจ `birdnet` (ONNX fp16) + โมเดลพื้นที่ geo 3.0 — ผลอยู่ในโฟลเดอร์
  ที่ลงท้าย `_v3preview` โมเดลอยู่ที่ `data/birdnet/` (ถ้าไม่มีจะโหลดให้ครั้งแรก)
- **3.0-pruned** (เลือกใน Settings แทน 2.4 ตั้งแต่ 2026-10-24): โมเดลรุ่นย่อ 71.5 MB
  (BirdNET+ V3.0-preview3.1 Global 11K FP16 pruned จาก Zenodo record 20703646 ชุดเดียวกับโมเดลเต็ม, CC BY-SA 4.0)
  โหลดผ่าน `birdnet.load_custom` ใช้ป้ายชื่อและโมเดลพื้นที่ชุดเดียวกัน Second look ใช้ได้ — ผลอยู่ในโฟลเดอร์ `_v3pruned`
  ไฟล์อยู่ที่ `data/birdnet/acoustic-models/v3.0-pruned/` (ถ้าไม่มีจะโหลดจาก Zenodo แล้วตรวจ md5)
  ทดลองแล้ว: เร็วกว่า ~16% แต่คลิปที่ตรวจแล้ว ID ถูกตกต่ำกว่า 0.5 ไป 14% (ข้อ 7) — ไว้เทียบผล
  REC-001: 108 คลิป (โมเดลเต็ม 109) ไม่มี Ring-necked Pheasant/Rock Pigeon ที่ผู้ตรวจ Reject แต่ก็ไม่มี Gray Wagtail/Eurasian Coot
- **2.4** (เหลือเฉพาะ command line `--model 2.4`): `birdnetlib` บน LiteRT (`ai-edge-litert`, ผ่าน shim
  `app/tflite_runtime`) — ไม่ใช้ TensorFlow
- หน้าต่าง 3 วิ เลื่อนทีละ 1.5 วิ, คะแนน ≥ min_conf

### 6.3 ตัวกรองพื้นที่/ฤดู
- โมเดล geo ให้ความน่าจะเป็นของแต่ละชนิดที่พิกัด + สัปดาห์ (48 สัปดาห์/ปี) — ผ่านเมื่อ ≥ 0.03
- **ตัดทิ้งเป็นค่าเริ่มต้น**: ชนิดนอกพื้นที่/ฤดู และเสียงที่ตรวจพื้นที่ไม่ได้ (แมลง กบ สัตว์อื่น)
- ชื่อวิทยาศาสตร์ของโมเดลเสียงกับโมเดลพื้นที่ต่างกัน ~900 ชื่อ — ถ้าไม่ตรงจะจับคู่ด้วยชื่อสามัญก่อน
- ต้องการดูนกหลงถิ่น: ติ๊ก *also keep out-of-area ≥* (เก็บพร้อมคำเตือน “No — verify by ear”)
- ตัวกรองรู้แค่พื้นที่กับฤดู ไม่รู้ถิ่นอาศัย → ข้อ 6.4

### 6.3b Second look — ฟังซ้ำเสียงที่ BirdNET เกือบเจอ (3.0, เพิ่ม 2026-10-24)
BirdNET ฟังทีละ 3 วินาทีตามเวลาตายตัว (0, 1.5, 3 …) เสียงสั้นที่คร่อมรอยต่อจึงถูกแบ่งครึ่งและได้คะแนนต่ำ
(โปรแกรมอ้างอิงตัดตัวเสียงก่อนแล้วจึงให้ BirdNET ฟัง จึงเจอบางชนิดที่แอปพลาด)
1. วิเคราะห์ที่เกณฑ์ 0.2 แล้วเลือกช่วงที่ชนิดนั้นได้ **0.2 ถึง min_conf**, **ผ่านตัวกรองพื้นที่/ฤดู** (และถิ่นอาศัย ถ้าติ๊ก)
   และไม่อยู่ติดคลิปของชนิดเดียวกัน (ห่างเกิน occurrence gap)
2. หาเสียงที่เด่นที่สุด 2 เสียงในช่วงนั้น (250–10000 Hz, ดังกว่าพื้นหลัง ≥ 9 dB) แล้วให้ BirdNET ฟังชนิดเดิมอีกรอบ 2 แบบ:
   หน้าต่าง 3 วิที่มีเสียงนั้นอยู่ตรงกลาง และตัวเสียงเดี่ยว ๆ เติมเงียบให้ครบ 3 วิ
3. คะแนนดีที่สุดถึง min_conf → ตัดเป็นคลิปตามปกติ คอลัมน์ *Found by* = `Second look: BirdNET 0.45 in its usual 3-s windows,
   0.58 for a 3-s window centred on the sound` และ *Max confidence* = คะแนนตอนฟังซ้ำ

ทดลองกับ REC-001 18 ต.ค. (1 ชม.): ฟังซ้ำ ~140 ช่วงใช้เวลาเพิ่มไม่ถึง 20 วิ ได้คลิปเพิ่ม 9 คลิป เช่น Gray Wagtail 0.48→0.58,
Eurasian Coot 0.45→0.53, Little Owl 0.32→0.76, Black Bulbul 0.33→0.63 (3 ชนิดแรกตรงกับที่โปรแกรมอ้างอิงรายงาน)
- ใช้เฉพาะชนิดที่ BirdNET ทายอยู่แล้วและโมเดลพื้นที่ว่าควรพบ: ถ้าให้ฟังตัวเสียงเดี่ยว ๆ ทั้งไฟล์ ได้ 78 ชนิดที่ ≥ 0.5
  ส่วนใหญ่ผิด (นกอเมริกา)
- ฟังซ้ำไม่ใช่ตัวยืนยัน: คลิปที่ตรวจแล้ว ID ผิด 2 ใน 3 ยังได้ ≥ 0.6 ตอนฟังซ้ำ — Review progress มีแถว
  *Found only by the second look* ไว้วัดว่าคลิปจากการฟังซ้ำถูกบ่อยแค่ไหน
- ผลที่วิเคราะห์ก่อนมีตัวเลือกนี้: ใช้ *Find sounds ▾ → Near misses* (ข้อ 7) แทนการวิเคราะห์ใหม่
- ปิดได้ใน Settings หรือ `--no-second-look`; รุ่น 2.4 ไม่มี

### 6.4 ตัวกรองถิ่นอาศัย (AVONET)
ใช้ถิ่นอาศัยหลักของแต่ละชนิดจาก AVONET (~13,600 ชื่อ, จับคู่กับรายชื่อนก BirdNET ได้ ~82%)
นกบกผ่านทุกจุด เพราะเดินทาง/ร้องจากที่ใกล้ ๆ ได้ — นกน้ำต้องมีแหล่งน้ำที่เข้ากัน:

| ถิ่นอาศัยของชนิด | ผ่านเมื่อจุดบันทึกมี |
|---|---|
| ป่า / ทุ่ง / พุ่มไม้ / เมือง ฯลฯ | ทุกแบบ |
| Wetland (รวมนกที่ใช้ชีวิตในน้ำ) | Marsh, River, Sea |
| Riverine | River, Marsh |
| Coastal | Sea, Marsh, River |
| Marine | Sea |

ไม่เข้ากันแต่คะแนน ≥ 0.8 → เก็บไว้ (อาจบินผ่าน) พร้อมคำเตือน *Check*
ชนิดที่ AVONET ไม่มีข้อมูล → ไม่ตรวจ

### 6.4b Checklist ของประเทศ (จีน ฮ่องกง ไต้หวัน ไทย)
เทียบชนิดกับ checklist ของประเทศที่บันทึก (ข้อมูลจาก Scythebill, ระบบชื่อ eBird/Clements 2025)
ทำงานในเครื่อง ไม่ต้องต่อเน็ต ไม่ต้องมี key — **เตือนเท่านั้น ไม่ตัดคลิปทิ้ง**

| ผล | ความหมาย |
|---|---|
| native / endemic / introduced | ปกติ |
| rarity, only escaped cage birds, extinct, not on the checklist | *Check* — ฟังให้แน่ใจก่อน Approve |
| …but split species X is — check the name | eBird แยกชนิดแล้ว แต่ BirdNET ยังใช้ชื่อเดิมกับทั้งกลุ่ม เช่น Striated Heron ในจีน = Little Heron, Western Cattle Egret ในไทย = Eastern Cattle-Egret → แก้ชื่อก่อน Approve |

- ประเทศดูจากพิกัด (เส้นเขตแดน Natural Earth 1:10m): จุดในทะเลห่างฝั่งไม่เกิน 10 กม. นับเป็นประเทศนั้น
  ใกล้ชายแดนทางบกยึดเส้นเขตแดน (คลาดได้ราว 1 กม.) นอก 4 พื้นที่นี้ = ไม่แสดง
- ชื่อ BirdNET ที่ไม่ตรงกับ eBird (~240 ชื่อ เช่น *Charadrius dubius* = *Thinornis dubius*) จับคู่ด้วยชื่ออังกฤษ
- ผลอยู่ในคอลัมน์ *Country checklist* และบรรทัด **Checklist:** ข้างปุ่ม Look up species ในแท็บ Review clips

### 6.5 Occurrence และคลิป
- เสียงของชนิดเดียวกันที่ห่างกัน ≤ occurrence gap รวมเป็น 1 occurrence = 1 คลิป ช่วงต่อเนื่องจาก
  (เสียงแรก − lead) ถึง (เสียงสุดท้าย + tail) ไม่เฉือนช่วงกลาง ไม่ต่อหลายช่วง
- อ่านเฉพาะช่วงจากไฟล์ต้นฉบับ (ไม่โหลดทั้งไฟล์), คง sample rate และ bit depth (24-bit/float → 24-bit)
- 32-bit float ที่ดังเกิน 0 dB (เครื่องอัด 32-bit): ลดเสียงทั้งคลิปลงก่อน ไม่ตัดยอดทิ้ง เสียงจึงไม่แตก
  และไม่ถูกนับเป็น Clipping (คอลัมน์ Peak ของคลิปแบบนี้เป็นค่าหลังลดเสียง)
- คง stereo ตามที่อัด (เลือก *to mono* ได้), normalize peak −3 dBFS, วัด peak/clipping/SNR/ความถี่ก่อน normalize
  ผลที่ตัดเป็น mono ไว้ก่อนแล้ว (ก่อน 2026-10-20) ไม่ถูกตัดใหม่ เพราะผลตรวจผูกกับไฟล์คลิปเดิม — ต้องการ stereo
  ให้ใช้ *force redo* (ผลตรวจของไฟล์นั้นกลับเป็น Pending)
- ชื่อคลิป `<วัน_เวลาเริ่ม>_<HHMM>_<Genus.species>_<SourceID>_<ลำดับ>_R0.wav` (R0 = ยังไม่ตรวจ)
- Keep continuous: รวมทุก occurrence ของชนิดเป็นช่วงเดียว (จำกัดขนาด ~350 MB ต่อช่วง)
- cut unknown: เสียงคะแนนต่ำกว่า min_conf (≥ 0.1) ที่ไม่ทับช่วงที่ระบุได้ → `_Unknown/`

### 6.6 Spectrogram และกรอบ
- mel-spectrogram ต่อคลิป (.png) สร้างใน process แยกหลังวิเคราะห์เสร็จ — เปิดจาก ปุ่ม BirdNET boxes ↗… → *Picture with
  BirdNET boxes ↗* (ตัวดูในแท็บ Review วาดสดจากคลิป ไม่ใช้ภาพนี้)
- **แถบขาวด้านบน** = ช่วงที่ BirdNET เจอชนิดนี้ + คะแนน (เชื่อได้)
- **กรอบฟ้า** = เสียงที่ดังกว่าพื้นหลังชัดเจน (≥ 12 dB) ภายในช่วงนั้น — ประมาณจากภาพ อาจเป็นนก
  ชนิดอื่นหรือแมลงที่ดังพร้อมกัน (BirdNET ตัดสินทั้งหน้าต่าง 3 วิ ไม่บอกว่าเสียงไหนเป็นของชนิดนั้น)
- **แกนล่างเป็นเวลาจริง** (นาฬิกาเครื่องอัด, HH:MM:SS ที่วินาทีเต็ม) ไว้เทียบกับเวลาในภาพถ่าย
  คลิปของ BirdNET เริ่มก่อนเสียงแรก 3 วิ (lead) — แถบขาวเริ่มตรงกับ Clock time ในตาราง
- ข้อมูลกรอบและเวลาต้นคลิปเก็บในไฟล์ภาพด้วย ภาพที่ไม่ตรงกับคลิปปัจจุบัน หรือวาดแบบเก่า (ก่อนมีแกนเวลาจริง)
  จะถูกวาดใหม่เอง: เปิดผลชุดเก่าในแท็บ Review แอปจะเพิ่มงาน *Redraw … spectrogram(s) with clock time*
  ในคิวครั้งเดียว (~17 วิ ต่อ 100 คลิป)
- เวลาจริงทั้งหมดมาจากนาฬิกาของเครื่องอัด (metadata/เวลาไฟล์) — ถ้านาฬิกากล้องกับเครื่องอัดไม่ตรงกัน
  ต้องบวก/ลบส่วนต่างเอง (เช่น ถ่ายภาพหน้าจอเครื่องอัดไว้เทียบ)

### 6.7 รันซ้ำ, หยุดกลางคัน, ความปลอดภัยของไฟล์
- **รันไฟล์เดิมซ้ำ**: ถ้าไฟล์ต้นทาง การตั้งค่า และคลิปตรงกับผลเดิม → ข้าม แล้วเปิดผลเดิมให้
  ถ้าการตั้งค่าเปลี่ยน → วิเคราะห์ใหม่ และเก็บผลตรวจของคลิปที่ได้เหมือนเดิมทุกไบต์
  ถ้าโฟลเดอร์นั้นมีคลิป Approved แล้ว → ข้าม ให้เลือกโฟลเดอร์ผลลัพธ์อื่นเพื่อเปรียบเทียบ
- **force redo**: สร้างคลิปใหม่ ตั้งผลตรวจกลับเป็น Pending
- **หยุดกลางคัน** (Stop / ปิดแอป / Ctrl+C): summary บันทึกทีละไฟล์ ไฟล์ที่เสร็จแล้วไม่ต้องวิเคราะห์ใหม่
- คลิปเขียนลงพื้นที่พักก่อน (`.staging`) แล้วย้ายเข้าที่ทีเดียว ถ้าพังกลางทางไม่มีไฟล์ครึ่ง ๆ กลาง ๆ
- ทุกคลิปและสำเนาใน Ready มี sha256 — ไฟล์ที่ถูกแก้จากภายนอก (เช่นใน Audacity) จะไม่ถูกเขียนทับ/ลบ

### Listening tools, Sound events และการทำงานร่วมกับโปรแกรมอื่น (เพิ่ม 2026-10-23)

**1. Listen tools… — ฟังตรวจโดยเลือกเวลาและย่านความถี่**

**Display: Prism** (ค่าเริ่มต้น) — หน้าเสียงของแอป เลือก Macaulay แทนได้ที่ช่อง Display:
- บนสุด = แถบควบคุม ขึ้นบรรทัดใหม่เองเมื่อหน้าต่างแคบ: **▶ Play / ■ Stop** (กรอบที่เลือก หรือจากขอบซ้ายของภาพ, เส้นเล่นเลื่อนตาม),
  **Speed** (Normal, 1/2, 3/4, 1.25, 1.5, 2 — คงระดับเสียง), **Channel** Left/Right (แสดงและเล่นทีละช่อง; mono = Mono),
  **Invert** (พื้นกระดาษ), **Wave dB** (คลื่นเสียงแบบค่าตัวอย่าง/dB), **Spectrogram** (เปิด/ปิด), **Log Hz** (ความถี่ linear/log),
  **Labels** (ป้ายชนิด), **Analysis**, **Brightness** (−96..96), **Contrast** (−96..−1 = ช่วง dB ของสี),
  **◀ Span / Span ▶** ช่วงก่อน/ถัดไปในไฟล์ (ยาวเท่าช่วงที่เปิด), **Save screen…** = บันทึกภาพหน้าเสียงเป็น PNG
- **ไอคอนปุ่ม**: วาง PNG ใน `app/assets/prism-icons/` ตามชื่อใน `README.txt` ของโฟลเดอร์นั้น ปุ่มจะแสดงไอคอนแทนตัวหนังสือ ไม่มีไฟล์ = ตัวหนังสือ
- กลาง = spectrogram FFT 256 จุด เลื่อนทีละ 128 (Hann), 0 dB = full scale พื้นเทาเข้ม เสียงเบาไปดัง = ม่วง ชมพู ส้ม เหลืองอ่อน
  เริ่มที่ 8 วินาทีต่อจอ 0–12 kHz
- ล่าง = คลื่นเสียงสีเขียวอมฟ้า (ค่าตัวอย่าง ±32768 หรือ dB เทียบ full scale) แถบแบ่งลากปรับความสูงได้
- แกนซ้ายตัวเลขเหนือเส้นขีด, แกนเวลาเริ่ม 0s ที่ขอบซ้าย (**ดับเบิลคลิกแกนเวลา** = เวลาจริงของนาฬิกาเครื่องอัด), ป้ายชนิดที่
  BirdNET ให้ ≥ 0.5 เหนือภาพ (จากดัชนีเสียง เฉพาะไฟล์ต้นฉบับ), เคอร์เซอร์กากบาทบอก *4.956175s 10.440kHz -95.9dB*
  (เวลาจากต้นไฟล์)
- ลากกรอบ = เลือกเวลา+ความถี่ (เติมช่อง Start/End/Low/High ให้), คลิกครั้งเดียว = ยกเลิก, คลิกขวา = เส้นอ้างอิงความถี่
  (สูงสุด 2 เส้น; ดับเบิลคลิกขวา = ลบ), คลิกขวาในกรอบ = ซูมพอดีกรอบ
- ปุ่ม + − Fit ทางซ้ายของภาพ = ซูมแนวตั้ง (Fit = ทุกความถี่), แถว **Time** ใต้ภาพ = ซูมเวลาเป็นขั้น 0.5–256 วินาทีต่อจอ (Fit = ทั้งช่วง)
  คีย์บอร์ด (คลิกภาพก่อน): ←/→ เลื่อน 1/10 จอ, Shift+←/→ ทั้งจอ, Space เล่น, + หรือ z ซูมเข้า, − ซูมออก, = พอดี
- **Analysis**: หน้าต่าง *Prism Analysis* — สเปกตรัมของกรอบที่เลือก
  (ไม่เลือก = ภาพที่เห็น) แกนตั้งเป็นความถี่ตาม spectrogram แกนนอนเป็น dB จากจุดสูงสุด 0 dB ไปทางขวา ยาวตามแถบ Contrast
  + ตาราง Tstart, Tend, Fstart, Fend, dBmin, dBmax, dBmean, Fpmin, Fpmax, Fpmean, Fppeak อัปเดตทันทีเมื่อลาก/เลื่อน/ซูม;
  คลิกขวาที่กราฟ = Copy values / Save picture… — สูตรเทียบกับโปรแกรมอ้างอิงด้วยไฟล์ทดสอบและ REC-001 (2026-10-24):
  - dBmin/dBmax/dBmean = พลังงานในย่านความถี่ของแต่ละเฟรม (sine แอมพลิจูด 0.1 = −20 dB, เสียงรบกวน RMS −40 dBFS = −40 dB)
    เฉลี่ย 2 เฟรมติดกัน; dBmean = พลังงานเฉลี่ย — ตรงกับโปรแกรมอ้างอิงภายใน 0.1 dB (REC-001 0–16 วิ: −70.66/−20.52/−39.85
    เทียบกับ −70.62/−20.54/−39.87)
  - Fpmean = ความถี่เฉลี่ยถ่วงด้วยพลังงาน (ตรง 0.533 kHz), Fppeak = จุดสูงสุดประมาณค่าแบบพาราโบลา (ต่างได้ ~0.1 kHz)
  - Fpmin/Fpmax = ไล่จาก Fppeak จนสเปกตรัมลงถึงค่ากลางของสเปกตรัม + 3.5 dB (คู่มือไม่บอกวิธีหาพื้นเสียงรบกวน: ตรงกับ REC-001
    และเสียงรบกวน แต่เสียง sine ล้วนแคบกว่าโปรแกรมอ้างอิง ~3 bin)
  - ค่า zero-crossing (N, Dur, TBC, Fc, Sc …, ใช้กับค้างคาว) แสดง — ไม่คำนวณ
  - ใช้ทำอะไร: วัดความถี่ของเสียงไว้เทียบกับเสียงอ้างอิง (ปุ่มด้านล่าง), วัดความดังของเสียงนกเทียบกับกรอบพื้นหลังในย่านเดียวกัน
    (ช่วยให้คะแนนคุณภาพ เช่น นกหัวขวาน REC-001 −52 dB กับพื้นหลัง −62 dB = เสียงเบา), และดูว่าเสียงรบกวนอยู่ย่านไหน
- **Compare with reference sounds (frequency and band)…** (ปุ่มในหน้าต่าง Prism Analysis หรือปุ่ม **Compare Hz…** ใต้ภาพในแท็บ
  Review) — เทียบเสียงของคุณกับเสียงอ้างอิง
  ของ**หลายชนิดพร้อมกัน** (เช่น Pale-legged กับ Sakhalin Leaf Warbler ที่ต้องแยกด้วยเสียง) ทั้ง 3 อย่าง: **ความถี่ที่ดังสุด**,

    เสียงที่เลือกได้, **เหลือง = ใช้อยู่**, แดง = กรอบที่ลากเอง

    - เปิดจาก Prism Analysis หลังลากกรอบไว้ใน Listen tools = ใช้กรอบนั้นเลย (ไม่ได้ลาก = Auto)

- **ความแม่น** (2026-10-20: ไฟล์ xeno-canto 679 ไฟล์ 110 ชนิด ทดสอบ 5 ส่วนกับไฟล์ที่ไม่ได้ใช้ฝึก): ถูก 79%
  ทุกครั้งที่ฝึก แอปทดสอบแบบนี้ใหม่แล้วตั้ง **เกณฑ์มั่นใจ** ให้คำเดาที่มั่นใจถูก ~90% (ตอนนี้ครอบคลุม 51% ของไฟล์
  ทดสอบ; คลิปของคุณ 282 จาก 651 คลิป) — มั่นใจแล้วแอปเติมช่อง Sound type ให้ ไม่มั่นใจแสดง *song?* ให้ฟังเอง
  (ป้ายของ xeno-canto ติดทั้งไฟล์ ไฟล์ "song" อาจมีเสียง call ปน ความแม่นจริงอาจต่างจากนี้เล็กน้อย)
- **flight call / alarm call / drumming** ตัวอย่างไม่พอ แอปไม่เดา — เลือกเอง
- คำเดาตอนบันทึกผลตรวจเก็บในคอลัมน์ *Sound type guess* (เช่น `Song 0.86 sure`) — Review progress บอกว่า
  คำเดาตรงกับที่คุณเลือกกี่ %
  (แยกคำเดาที่มั่นใจกับไม่มั่นใจ; คำเดาที่มั่นใจถูกเติมให้ จึงอาจดูตรงมากกว่าความจริงถ้าไม่ได้ฟังก่อนกด)

### Review progress… (วัดว่าตัวกรองไหนช่วยได้จริง)
ปุ่มในแท็บ Review clips รวมผลทุกชุดจากทุกโฟลเดอร์ผลลัพธ์ (ดู [ข้อ 8](#8-ผลลัพธ์และ-summaryxlsx)):
- **แถบความคืบหน้า**: ตรวจแล้วกี่คลิปของ BirdNET (เป้า 100–200 คลิป หลาย ๆ ชนิด) — Approved / ID ผิด
- **ตาราง Filters**: แต่ละตัวกรอง แยกคลิปที่ตรวจแล้วเป็น "ถูกเตือน" กับ "ไม่ถูกเตือน" แล้วนับ ID ผิดแต่ละฝั่ง
  เมื่อแต่ละฝั่งมี ≥ 10 คลิป จะสรุปว่าตัวกรองจับ ID ผิดได้กี่ % และเตือนผิด (ID ถูก) กี่ %
  - **ID ถูก** = Approve ด้วยชนิดเดียวกับ BirdNET (คะแนนเท่าไรก็ได้) — **ID ผิด** = Reject หรือ Approve หลังแก้ชนิด
    — **Not sure** ไม่นับ (ไม่ใช้วัดตัวกรองและฝึกโมเดล)
  - คลิปที่เพิ่มเองไม่นับ (BirdNET ไม่ได้ทาย)
  - ตัวกรองพื้นที่/ฤดูของ BirdNET, ถิ่นอาศัย และ checklist **ตัดชนิดทิ้งก่อนตัดคลิป** จึงแทบไม่มีคลิปให้วัด —
    อยากวัดตัวกรองเหล่านี้ ให้วิเคราะห์บางไฟล์โดยติ๊ก *also keep out-of-area* (เก็บไว้พร้อมคำเตือนแทนการตัดทิ้ง)
  - ที่วัดได้ตอนนี้: eBird ช่วงเดียวกันของปีก่อน ๆ, คะแนน BirdNET < 0.6, เสียงที่ไม่ใช่นกดังแข่ง,
    Second opinion เห็นต่าง (สองตัวหลังจากงาน Auto-checks), คลิปที่ได้จากการฟังซ้ำ (ข้อ 6.3b)
- **ML model — learns from your reviews**: เมื่อมีผลตรวจ ≥ 150 คลิป (ID ผิด ≥ 30, ID ถูก ≥ 30) แอปฝึก
  Random Forest และ logistic regression (scikit-learn ในโปรแกรม ไม่ต้องติดตั้งเพิ่ม) จากสัญญาณที่มีอยู่แล้ว:
  คะแนน BirdNET, ห่างจากชนิดอันดับ 2, จำนวนช่วงที่เจอ, ความยาว, SNR, ระดับเสียง, คำเตือนพื้นที่/ถิ่นอาศัย/checklist/
  eBird ปีก่อน ๆ, แมลงดังแข่ง, Second opinion แล้ววัดแบบ cross-validation 5 ส่วน **แบ่งตามไฟล์ต้นฉบับ**
  (ทดสอบกับไฟล์ที่โมเดลไม่ได้เรียน) เทียบกับการใช้คะแนน BirdNET อย่างเดียว — บอกค่า AUC, ถ้าเตือนจำนวนเท่ากับ
  "score < 0.6" จับ ID ผิดได้กี่คลิป และสัญญาณที่สำคัญที่สุด ต้องดีกว่าคะแนนอย่างเดียว ≥ 0.03 จึงนับว่าช่วย
  ระหว่างข้อมูลไม่พอจะบอกว่าต้องตรวจเพิ่มอีกเท่าไร
  - **เตือนในตาราง**: ถ้าทดสอบแล้วดีกว่าคะแนนอย่างเดียว แอปฝึกโมเดลที่ดีที่สุดกับผลตรวจทั้งหมด (เบื้องหลัง ~2 วิ
    ตอนเปิดผลชุด; ฝึกใหม่ทุก 5 ผลตรวจที่เพิ่ม) แล้วใส่ **Check** ให้คลิปที่ความเสี่ยงถึงเกณฑ์ + บรรทัด
    *⚠ ML model: BirdNET IDs like this were often wrong in your reviews (risk 89%)* — เกณฑ์ตั้งให้เตือนจำนวนเท่ากับ
    กฎ "score < 0.6" ในการทดสอบ (2026-10-20: 164 ผลตรวจ เตือน 56 จับ ID ผิด 28 จาก 38 เทียบกับ 23 ของกฎคะแนน;
    คลิปที่ยังไม่ตรวจ 499 คลิป โมเดลเตือน 72 คลิป เป็นคลิปที่ตัวกรองอื่นไม่ได้เตือน 43 คลิป)
    ถ้าโมเดลไม่ดีกว่าคะแนนอย่างเดียว จะไม่เตือนเลย
  - ปุ่ม **▶ Review riskiest clip**: เปิดคลิปที่ยังไม่ได้ตรวจซึ่งโมเดลว่าเสี่ยงที่สุด (ทุกผลชุด) กดต่อ = คลิปถัดไป;
    ข้างปุ่มบอกว่าเตือนกี่คลิป และกี่คลิปที่ตัวกรองอื่นไม่ได้เตือน
- **Sound type guess — song / call**: ฝึกจากกี่ไฟล์/กี่คลิปของคุณ, ผลทดสอบ, คำเดาตรงกับที่คุณเลือกกี่ %,
  เดาผิดแบบไหน (เช่น *guessed call but you chose song ×6*), คำเดาของคลิปที่ยังไม่ได้ตรวจ — ปุ่ม
  **▶ Label an unsure clip** เปิดคลิปที่ตัวเดาลังเลที่สุด: เลือก Sound type ให้คลิปพวกนี้ ตัวเดาเรียนได้มากที่สุด
- **Sound types…** (ปุ่มในส่วนเดียวกัน): รายการคลิปทุกผลชุดพร้อมคำเดา เลือกดูกลุ่ม *Not sure* (ก้ำกึ่งที่สุดก่อน),
  *Guessed song / call (sure)*, *Different from your choice*, *Your choices* — เลือกคลิป = เห็นภาพ (คลิก = เล่น),
  กดปุ่มหรือปุ่มลัด **s** Song, **c** Call, **f** Flight call, **a** Alarm call, **d** Drumming, **o** Other
  (space = เล่น) → บันทึกลงคอลัมน์ Sound type ทันที **ไม่เปลี่ยนสถานะการตรวจ** แล้วไปคลิปถัดไป ตัวเดาฝึกใหม่เบื้องหลัง
  — คลิปที่ยัง Pending ที่เลือกประเภทแล้วก็ใช้ฝึกได้; ไม่แสดงคลิปที่ Reject/Not sure; ดับเบิลคลิก = เปิดในแท็บ Review
- **ตาราง Species**: ต่อชนิด (ชื่อ eBird) — จำนวนคลิป, ตรวจแล้ว, ✓, ✗ ID ผิด, ยังไม่ตรวจ, ถูกเตือน, กี่ผลชุด
  เลือกดูเฉพาะ *Not reviewed yet / Warned by a filter / Has wrong IDs*; **ดับเบิลคลิก = แท็บ Review แสดงเฉพาะชนิดนั้น**
  และเปิดคลิปถัดไปที่ยังไม่ได้ตรวจ (ตรวจครบแล้ว: เปิดผลชุดล่าสุดที่มีชนิดนั้น)
- **▶ Review next suggested clip**: เลือกคลิปของชนิดที่ตรวจน้อยที่สุด (คลิปที่ถูกเตือนก่อน) เปิดในแท็บ Review ให้
  — ทุกชนิดและทุกตัวกรองจะได้ถูกทดสอบเท่า ๆ กัน

## 8. ผลลัพธ์และ summary.xlsx

เก็บผลแยกตามวันได้: แอปรวมผลจากทุกที่ให้เองในเมนู Results, Review progress, Recorder flags, Sound types และตัวฝึกที่เรียนจากผลตรวจ
คือ Output folder ปัจจุบัน + ทุกโฟลเดอร์ที่เคยวิเคราะห์หรือเปิดผล (จำใน `data/settings.json`) + `~/BirdNET_eBird` +
`<Birding>/<ปี>/<เดือน>/<วัน>/Sounds/Done` ทุกวันใต้ Birding ที่เคยเพิ่ม Field log ไม่ต้องเปลี่ยน Output folder กลับไปกลับมาเพื่อดูผลเก่า
เลือกโฟลเดอร์ `Sounds` มาวิเคราะห์ได้เลย: แอปข้ามทุกอย่างใน `Done` และ `Ready`

**Upload sheet…** ในแท็บ Review clips เขียน `<วัน>/Ready/upload-sheet.csv` แล้วเปิดให้ดูคู่กับหน้า eBird: ทุกไฟล์ใน Ready ของวันนั้น เรียงตามชนิดและเวลา
กดใหม่เมื่อตรวจเพิ่ม แอปไม่เขียนไฟล์นี้เอง
| คอลัมน์ | ใช้ทำอะไรตอนอัปโหลด |
|---|---|
| Checklist | checklist ของไฟล์เสียงนั้น รายการเรียงตามคอลัมน์นี้ อัปโหลดทีละ checklist ได้ (ว่าง = ไม่มี Log หรือเลือก No checklist) |
| Species, Scientific name, Time, File | ไฟล์นี้ลงชนิดไหน |
| Quality, Sound type, Notes | คะแนน แท็กเสียง และหมายเหตุ |
| Additional species | ชนิดเสียงพื้นหลังที่คุณบันทึกไว้ ใส่ช่อง Additional Species ใน Manage Media |
| Add to checklist first | ชนิดที่ไม่อยู่ใน checklist ของไฟล์เสียงนั้น (ดูจาก Field log ไม่มี Log = ว่าง) eBird เลือกเป็น Additional Species ไม่ได้จนกว่าจะเพิ่มด้วย Edit Species List จำนวน X ก่อน |
| BirdNET also heard | ชนิดที่ BirdNET เจอระหว่างคลิปแต่ไม่ได้บันทึกไว้ **ยังไม่ยืนยัน** ฟังก่อน ถ้าได้ยินจริงให้เปิดคลิปแล้วคลิกช่อง Background species เลือกเพิ่ม |

eBird แนะนำว่าชนิดที่เสียงเบาให้ใส่เป็นเสียงพื้นหลัง ส่วนชนิดที่ชัดทั้งคู่ให้ตัดคลิปแยกของแต่ละชนิด ไม่อัปไฟล์เดียวกันซ้ำ และรับสื่อได้ 10 ไฟล์ต่อชนิดต่อ checklist

| Review status, Reviewed common/scientific, Quality rating, Review notes, Ready file, Ready sha256 | ผลตรวจของคน |
| Origin | `Manual` = คลิปที่ผู้ตรวจเพิ่มเอง หรือเพิ่มจาก Find sounds (ว่าง = คลิปของ BirdNET) |
| Sound type, Sound type guess | ประเภทเสียงที่ผู้ตรวจเลือก + คำเดาของแอปตอนบันทึก (เช่น `Song 0.86 sure`) |
| Background species | ชนิดเสียงพื้นหลังในคลิป ชื่อตาม eBird คั่นด้วย `;` (เช่น `Light-vented Bulbul; Spotted Dove`) ไว้ใส่ตอนอัปโหลด |

## 9. ข้อมูลของแอป: โฟลเดอร์ `data/`

ทุกอย่างที่แอปสร้างเองอยู่ใน `data/` ของโฟลเดอร์โปรแกรมที่เดียว (ย้าย/สำรองทั้งโฟลเดอร์โปรแกรมได้)

| ที่อยู่ | มีอะไร | ลบได้ไหม |
|---|---|---|
| `data/settings.json` | API key ของ xeno-canto/eBird, ผลชุดล่าสุดที่เปิด (สิทธิ์ 600) — **ส่วนตัว ห้ามส่งให้คนอื่น** | ได้ (ต้องใส่ key ใหม่) |
| `data/analysis-presets.json` | ชุดตั้งค่าที่ตั้งชื่อไว้ อาจมีพิกัดสถานที่ (ไม่รวมใน share zip) | ได้ (ชุดตั้งค่าหาย) |
| `data/cache/recorder-flags/` | flag ของแต่ละไฟล์ต้นฉบับ เผื่อย้ายไฟล์ออกไป | ได้ (อ่านจาก WAV ใหม่) |
| `data/field-logs.json` | eBird checklist ของคุณที่เพิ่มจากลิงก์หรือโฟลเดอร์ Log + โฟลเดอร์ Birding + ไฟล์เสียงที่เลือก checklist ไว้ (ไม่รวมใน share zip) | ได้ (กดเพิ่มใหม่) |
| `data/birdnet/` | โมเดล BirdNET 3.0 + รุ่นย่อ pruned + geo + taxonomy (~370 MB) | ได้ (โหลดใหม่ตอนใช้) |
| `data/cache/xeno-canto/` | ไฟล์เสียงอ้างอิงที่เคยฟัง | ได้ |
| `data/cache/second-opinion/` | ผล Second opinion + embedding อ้างอิง | ได้ (คำนวณใหม่) |
| `data/cache/sound-type/`, `data/cache/xeno-canto-types.json` | เวกเตอร์ของคลิป, ตัวเดา Song/Call, ประเภทเสียงของไฟล์ xeno-canto | ได้ (คำนวณใหม่) |
| `data/cache/ebird/` | ระบบชื่อ eBird (60 วัน), hotspot/รายชื่อชนิด (7 วัน), รายงานล่าสุด (6 ชม.) | ได้ |
| `data/cache/sound-index/` | ดัชนีเสียงของไฟล์ต้นฉบับ (~6 MB/ชม. เสียง) + ผลจัดกลุ่ม/Near misses/Expected species ล่าสุด | ได้ (ทำใหม่ ~2 นาที/ชม.) |
| `data/cache/signal-events/` | ขอบเขตเหตุการณ์เสียงและ embeddings ของตัวเสียงที่แยกแล้ว | ได้ (สแกน/เข้ารหัสใหม่) |
| `data/cache/recognizers/` | ตัวจำแนกของคุณ (ต่อชนิด) | ได้ (ฝึกใหม่ได้ทันที) |
| `data/cache/frequency-refs/` | ผลวัดความถี่ของเสียงอ้างอิง + ผลค้น xeno-canto (7 วัน) + `vectors/` เวกเตอร์ BirdNET ของเสียงอ้างอิง (Train on references) | ได้ (วัดใหม่) |
| `data/reference-sounds/` | ไฟล์เสียงอ้างอิงที่คุณเพิ่มเองใน Compare frequencies (ไม่รวมใน share zip) | ระวัง: ไฟล์ของคุณเอง |
| `~/Library/Logs/BirdNET-eBird.log` | log ของตัวเปิดบน Desktop (ข้อยกเว้นเดียวที่อยู่นอก `data/`) | ได้ |

- รุ่นก่อนเก็บไว้ใน `~/Library/Application Support` และ `~/Library/Caches`
  แอปย้ายเข้า `data/` ให้เองตอนเปิด (ไม่ทับของที่มีอยู่แล้ว)
- ถ้าโฟลเดอร์โปรแกรมเขียนไม่ได้ (เช่นเปิดจากดิสก์อ่านอย่างเดียว) แอปจะกลับไปใช้ที่เดิมใน `~/Library`
- ผลวิเคราะห์ (คลิป, spectrogram, summary.xlsx) ไม่อยู่ใน `data/` แต่อยู่ในโฟลเดอร์ผลลัพธ์ที่เลือก
  (ค่าเริ่มต้น `~/BirdNET_eBird/`)
- **อย่าแก้สคริปต์ใน `BirdNET eBird.app/Contents/MacOS/`** — macOS ผูกสิทธิ์เข้าถึงโฟลเดอร์ Desktop
  ไว้กับเนื้อหาไฟล์นั้น แก้แล้วแอปจะเปิดไม่ขึ้น ("could not start" โดยไม่มีอะไรใน log)
  ถ้าเผลอแก้ไปแล้ว: คืนไฟล์เดิม หรือให้สิทธิ์ใหม่ใน System Settings › Privacy & Security ›
  Files & Folders › BirdNET eBird › Desktop Folder

## 10. ใช้ผ่าน Command line

```bash
cd "/Users/<you>/Desktop/Projects/Sound Recording/Programs/BirdNET-eBird-mac"
./BirdNET-eBird.command ~/Desktop/Birding/REC-002.WAV --coords 30.5928,114.3055 --habitat forest --spectrogram
./BirdNET-eBird.command ~/Desktop/Birding/Sounds --date 20261006 --same-date-for-all --coords 30.5,114.4
./BirdNET-eBird.command --help
```

| ตัวเลือก | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `audio` | – | ไฟล์หรือโฟลเดอร์ |
| `-o, --output` | `~/BirdNET_eBird` | โฟลเดอร์ผลลัพธ์ |
| `--coords LAT,LON` / `--lat` `--lon` | – | พิกัด (รับลิงก์ Google Maps) |
| `--date` | – | `YYYYMMDD` หรือ `YYYY-MM-DD` |
| `--start-time` | – | `HHMM`, `HHMMSS` หรือ `HH:MM` |
| `--same-date-for-all` | ปิด | ยืนยันว่า `--date` ใช้กับทุกไฟล์ในโฟลเดอร์ |
| `--fill-missing-metadata` | ปิด | ใช้ `--date/--coords/--start-time` เฉพาะไฟล์ที่ขาด |
| `--use-metadata / --no-use-metadata` | เปิด | อ่าน metadata ในไฟล์ |
| `--use-filetime` | ปิด | บังคับใช้เวลาไฟล์ |
| `--model {3.0-preview,3.0-pruned,2.4}` | 3.0-preview | โมเดลเสียง (3.0-pruned = รุ่นย่อ, 2.4 = รุ่นเก่า) |
| `--min-conf` | 0.5 / 0.25 | คะแนนขั้นต่ำ |
| `--overlap` | 1.5 | ช่วงซ้อนของหน้าต่าง 3 วิ |
| `--habitat forest,marsh,…` | – | forest, field, marsh, river, sea |
| `--out-of-range-min-conf` | ปิด | เก็บชนิดนอกพื้นที่ที่คะแนนถึงค่านี้ |
| `--occurrence-gap`, `--lead`, `--tail` | 5, 3, 3 | วินาที |
| `--target-dbfs` | −3 | normalize peak |
| `--format` | wav | นามสกุลคลิป (wav, flac, mp3 …) |
| `--place` | – | ชื่อสถานที่ |
| `--datetime-regex` | (ดู --help) | regex อ่านวันเวลาจากชื่อไฟล์ |
| `--mono / --no-mono` | ปิด | stereo → mono |
| `--spectrogram / --no-spectrogram` | **ปิด** (GUI เปิด) | สร้างภาพ |
| `--alt-species / --no-alt-species` | เปิด | |
| `--unknown`, `--unknown-min-conf` | ปิด, 0.1 | ตัด `_Unknown/` |
| `--keep-continuous` | ปิด | ช่วงต่อเนื่องต่อชนิด |
| `--second-look / --no-second-look` | เปิด | 3.0: ฟังซ้ำเสียงที่เกือบเจอ (ข้อ 6.3b) |
| `--force` | ปิด | วิเคราะห์ใหม่ + ล้างผลตรวจ |

โหมดพิเศษ (GUI ใช้เรียกเบื้องหลัง):
- `--group clip1.wav clip2.wav … -o out.wav` — รวมคลิป (Merge clips)
- `--sort-ready YYYY-MM-DD [โฟลเดอร์ผลลัพธ์]` — ย้ายคลิปที่ตรวจแล้วของวันนั้นเข้าโฟลเดอร์ checklist ใน Ready
- `--gen-spectrograms <โฟลเดอร์วัน> …` — สร้าง/ซ่อม spectrogram
- `--second-opinion <summary.xlsx> <แถว>` — คำนวณ Second opinion (อ่าน key จาก settings.json)
- `--separate <spec.json>` — Train on references ของตัวเทียบเสียง (บรรทัดสุดท้าย `SEPARATE {json}`)
- `--auto-checks <summary.xlsx>` — ตรวจอัตโนมัติทุกคลิปที่ยังไม่ได้ตรวจ (แมลง/กบดังแข่ง + second opinion < 0.65)
- `--manual-clip add --summary S --source REC.WAV --start 903 --end 912.5 --recorded 2026-10-18T14:39:44
  --lat 30.54 --lon 114.36 --common "…" --scientific "…" [--sound-type Call]` — เพิ่มคลิปที่เลือกเอง
- `--manual-clip suggest --source … --start … --end … --recorded … --lat … --lon …` — BirdNET เดาเฉพาะช่วง
- `--manual-clip add-batch items.json` — เพิ่มหลายคลิปทีเดียว (รายการ JSON แบบเดียวกับ add) ข้ามช่วงที่มีคลิปชนิดนั้นแล้ว
- `--sound-index build <summary.xlsx หรือไฟล์เสียง> …` — ทำดัชนีเสียงของไฟล์ที่ยังไม่มี
- `--sound-index groups <summary.xlsx> [--include-clipped]` — จัดกลุ่มเสียง (ผลอยู่ใน `data/cache/sound-index/groups-*.json`)
- `--sound-index near <summary.xlsx>` — เสียงที่เกือบเจอ + ฟังซ้ำ (`near-*.json`, ทำดัชนีให้ก่อนถ้ายังไม่มี)
- `--sound-index expected <summary.xlsx>` — ชนิดที่โมเดลพื้นที่ว่าควรพบที่จุด/สัปดาห์ของผลชุด (`expected-*.json`)
- `--recognizer train "Genus species" <summary.xlsx> …` — ฝึกตัวจำแนกจากผลตรวจในผลชุดเหล่านั้น

exit code: `0` สำเร็จ, `1` มีไฟล์ล้มเหลว, `2` ข้อมูลไม่ครบ/ค่าผิด, `130` ถูกหยุด

## 13. ข้อจำกัดที่ควรรู้

- BirdNET บอกได้แค่ชนิด ไม่บอกประเภทเสียง (song / call) และไม่บอกว่าเสียงไหนในหน้าต่าง 3 วิเป็นของชนิดนั้น
- ชนิดที่ BirdNET แทบไม่รู้จักจะพลาด (เช่น Yellow-billed Grosbeak ในไฟล์ 2026-10-01: คะแนน 0.005)
  การลด min_conf ทั่วไปจะเพิ่มผลผิดจำนวนมาก (ดู `accuracy_cases/`)
- ตัวกรองพื้นที่ใช้ time zone และพิกัดที่ถูกต้อง — time zone ของเครื่องผิด = เวลาจากไฟล์ UTC ผิด
- ถิ่นอาศัยจาก AVONET มีชนิดละ 1 แบบ และจับคู่ได้ ~82% ของรายชื่อ
- eBird ในหลายพื้นที่มีรายงานน้อย: "ไม่มีรายงาน" ≠ "ไม่มีนก"; รายงานล่าสุดย้อนได้ 30 วัน
- Checklist ของประเทศมีแค่ระดับประเทศ (ไม่แยกมณฑล/จังหวัด) และมีแค่จีน ฮ่องกง ไต้หวัน ไทย;
  นกหลุดกรงและนกหลงที่ยังไม่ได้รับรองส่วนใหญ่ไม่อยู่ในรายชื่อ จึงขึ้น *not on the checklist*
- xeno-canto: เสียงอ้างอิงบางไฟล์มีนกชนิดอื่นปน, บางชนิดมีไฟล์น้อย, เว็บมีระบบกันบอต (เบราว์เซอร์ปกติใช้ได้)
- Second opinion ยังไม่ได้วัดความแม่นยำกับคลิปที่คนตรวจ — ตรวจคลิปมากขึ้นแล้วจึงประเมินได้
- Find sounds เทียบทีละหน้าต่าง 3 วิ ซึ่งรวมเสียงพื้นหลังและนกตัวอื่นที่ร้องพร้อมกัน: "คล้าย" ≠ "ชนิดเดียวกัน" ต้องฟังเสมอ
  เสียงสั้นมาก/เบามากในช่วงที่นกอื่นร้องดังอาจไม่ขึ้น; Sound groups ไม่ได้แยกพยางค์ทีละเสียง (ใช้หน้าต่าง
  3 วิในโหมดเดิม) และเลือกเฉพาะช่วงที่ BirdNET ว่าคล้ายนกหรือดังมาก; โหมด Sound events แยกเหตุการณ์ก่อน
  แต่ยังพลาดเสียงที่ไม่ผ่านเกณฑ์ความถี่/ระยะเวลา/ความเด่นเหนือพื้นหลังได้; ตัวจำแนกที่ฝึกจากคลิปน้อยยังพลาดบ่อย
- เล่นเสียงใช้ `afplay` ของ macOS
